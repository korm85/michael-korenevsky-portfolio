Network & Firewall Configuration

Firewall rules

  • Rules implemented to allow downloading packages from the Oqton package source and the Ubuntu and Docker repositories (included in the prerequisites package).

OT network (operational technology)

  • Virtual Gateway and printers are on the same network.
  • Virtual Gateway has a fixed IP address.
  • Virtual Gateway and printers can communicate on the network.
  • Virtual Gateway can reach the Build Archive on port 445.

IT network

  • AMVero Client is installed in the IT network, accessible by end users.
  • Web Client has a fixed IP address.
  • Web Client and Virtual Gateway can communicate on the network.
  • Web Client can reach the Build Archive on port 445.

Printer Firmware & Connectivity

  • Supported firmware for IoT and build monitoring is installed.
  • OPC UA server details recorded (IP, port, schema, certificate, credentials) where applicable.
  • OEM connection clients configured for the machines in scope.
  • Minimum supported firmware versions confirmed for each connected machine.

Remote Support

Oqton maintains no direct or persistent remote connection to the system; support access is activated only upon customer initiation.

  • Screen-sharing / remote-support access arranged for setup assistance when the customer initiates it.

Operational Responsibilities & Data Management

Real-time monitoring performance

  • Customer ensures the provided hardware and network resources remain dedicated and within specification to prevent lag or interruptions in the live monitoring stream.

Data retention

  • Customer acknowledges that build records are retained only while disk space permits. When the Build Archive is full, the oldest records are automatically overwritten — regular backups are strongly recommended to avoid data loss.
